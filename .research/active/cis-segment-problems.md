# Проблемы целевой аудитории СНГ

**Status**: active  
**Date**: 2026-03-26  
**Project**: Tim Agents

## Question

Какие боли и проблемы решает Tim Agents для целевой аудитории в СНГ? Какие сценарии использования наиболее востребованы?

## Context

Tim Agents позиционируется как платформа автономных AI-агентов для массового рынка СНГ. Для корректного позиционирования и приоритизации фич необходимо понимать конкретные проблемы пользователей в каждом сегменте.

## Options Investigated

### Сегмент 1: Фрилансеры (2+ млн в России)

**Проблемы:**

| Проблема | Данные | Источник |
|----------|--------|----------|
| 60-70% времени — не работа, а рутина | Поиск заказов, общение, КП | neuroscribe.ru |
| 50-100 откликов на проект | Конкуренция на биржах | Kwork, Freelance.ru |
| Follow-up проваливается | Нет напоминаний | Опросы |
| Творческий блок | Не знают, что писать | Кейсы |

**Сценарии:**
- Поиск заказов: 2-3 ч/день на мониторинг бирж
- След-up: забывают перезвонить, теряют клиентов
- Документы: КП вручную, нет шаблонов
- База знаний: ответы на типовые вопросы не систематизированы

---

### Сегмент 2: Малый бизнес (1.5+ млн в России)

**Проблемы:**

| Проблема | Данные | Источник |
|----------|--------|----------|
| Потеря заявок | Человеческий фактор | incrussia.ru |
| 68% используют ИИ в одном направлении | Не используют агенты 24/7 | РБК |
| Синхронизация между системами | CRM ↔ мессенджеры ↔ почта | klerk.ru |
| Экономия до70% на рутине | Потенциал автоматизации | РБК |

**Сценарии:**
- Лиды: заявки не попадают в CRM, звонки не фиксируются
- Follow-up: забывают об оплате, нет напоминаний
- Поставщики: мониторинг цен вручную, часы гугления
- Документы: счета/акты вручную, нет шаблонов

---

### Сегмент 3: Блогеры/SMM

**Проблемы:**

| Проблема | Данные | Источник |
|----------|--------|----------|
| Контент-планирование = часы | Каждую публикацию планируют | weeek.net |
| 11 соцсетей для публикации | VK, Telegram, Дзен, YouTube... | SMMplanner |
| Аналитика разрознена | Данные в разных системах | LiveDune |
| Рынок SMM +35% в 2024 (65 млрд₽) | Растущий рынок | Ingate |

**Сценарии:**
- Контент-планирование: календарь в таблицах, нет связи с автопостингом
- Публикация: каждая соцсеть — отдельный вход
- Аналитика: данные в разных системах, нет сводного отчёта
- Мониторинг: конкуренты проверяются вручную

---

### Сегмент 4: Офисные сотрудники (P1, Phase 2)

**Проблемы:**
- Email переполнен: 120писем/день
- Встречи: 23ч/неделя
- Отчёты: сбор данных из разных систем
- Календарь: не синхронизирован

---

### Сегмент 5: Инвесторы (P1, Phase 2)

**Проблемы:**
- Мониторинг портфеля: вручную проверяют котировки
- Новости: разрозненные источники
- Due diligence: ручной сбор данных
