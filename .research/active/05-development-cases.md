**Dorial** - https://habr.com/ru/users/Dorial/

### Мотивация

Волна хайпа ИИ-агентов докатилась до автора в марте 2025 года. К тому времени:
- 7 месяцев общения с ChatGPT
- 1 месяц изучения Python и Machine Learning
- Опыт создания простого Telegram-бота

**Задача:** Создать ИИ-агента для поиска вакансий по расписанию

---

### Технологический стек

| Компонент | Технология | Функция |
|-----------|-----------|---------|
| Интерфейс | Telegram-бот | Взаимодействие с пользователем |
| LLM | ChatGPT + OpenAI Assistant API | Обработка запросов |
| Планировщик | APScheduler | Запуск по расписанию |
| Поиск | SerpAPI / DuckDuckGo | Веб-поиск |
| Парсинг | BeautifulSoup | Извлечение данных |
| Хранение | .txt, .json | Локальное хранение |
| Язык | Python | Основной язык |

---

### Ключевые открытия

#### Открытие №1: API ChatGPT не имеет веб-поиска

> "Перед тем как строить новый AI продукт, надо убедиться, что технологический стек подходит под задачу."

**Проблема:** ChatGPT через API не имеет доступа к веб-поиску.

**Решение:** OpenAI Assistant API + SerpAPI / DuckDuckGo

---

#### Открытие №2: LLM - только "переводчик"

> "Не 'ИИ-агент делает сайт за 2 часа', и не 'ИИ-агент ищет вакансии' — ИИ в этой экосистеме выступает лишь переводчиком запроса пользователя в понятную для программы инструкцию."

**Архитектура:**

```
Пользователь → Telegram Bot → LLM (формирует промпт) 
    → SerpAPI (поиск) → LLM (интерпретация) → Пользователь
```

---

#### Открытие №3: Нужны строгие обработчики

> "Чтобы ИИ-агент работал стабильно, его нужно окружить строгими обработчиками и четкими системными инструкциями."

**Проблема:** ChatGPT через API теряет контекст и историю чата.

**Решение:** Жесткое программирование промптов и обработчиков на Python.

---

### Архитектура итоговая

| Компонент | Функция |
|-----------|---------|
| Telegram-бот | Интерфейс взаимодействия |
| LLM (ChatGPT 4o) | Преобразует задачу в поисковый запрос |
| APScheduler | Планирование задач |
| SerpAPI / DuckDuckGo | Веб-поиск |
| BeautifulSoup | Парсинг результатов |
| Локальное хранилище | Сохранение задач |
| Python | Основная логика |

---

### Ограничения

1. **Поиск зависит от качества запроса** - не всегда точные результаты
2. **LLM не фильтрует** - нужен дополнительный слой обработки
3. **Интернет не создан для ИИ** - антискрейпинг, CAPTCHA, paywalls

---

### Что бы автор хотела в идеале (Мила 2.0)

- ИИ-агент сам парсит HTML-страницы
- Анализирует содержимое
- Работает над ответом с переводом
- Прислает выжимку

**Препятствие:** Интернет не создан для ИИ - он создан для глаз, кликов, эмоций.

---

### Гибридные схемы (как работают компании)

1. **Headless-браузеры (Playwright)** - маскируются под человека
2. **RAG-шлюзы** - сайт отдает данные в JSON через API
3. **Этичный скрейпинг** - ограничение скорости, кэширование
4. **Лицензии на данные** - revenue sharing с владельцами

## Кейс 2: Локальный AI-агент для России

### Источники
- Habr: "Я сделал локального AI-агента для России"
- VC.ru: Аналогичные кейсы

---

### Преимущества локального агента

| Параметр | Локальный | Облачный |
|----------|-----------|----------|
| VPN | Не требуется | Требуется |
| Подписка | Нет | Да |
| Облако | Нет | Да |
| Данные | На вашей машине | На серверах |

---

### Проблемы локальных агентов

1. **Требует мощное железо** - GPU обязательно
2. **Ограниченная модель** - не GPT-4
3. **Сложность настройки** - технические знания
4. **Нет синхронизации** - только локально

---

### Технологический стек

| Компонент | Вариант |
|-----------|---------|
| Модель | GigaChat / YandexGPT / Open-source LLM |
| Инференс | Ollama / LM Studio |
| Интерфейс | CLI / Web UI |
| Железо | GPU 8+ GB VRAM |

---

### Рекомендации

**Для кого подходит:**
- Разработчики
- Компании с высокими требованиями к безопасности
- Те, кто не может использовать VPN

**Для кого НЕ подходит:**
- Обычные пользователи
- Малый бизнес без IT-специалистов
- Те, кому нужна максимальная умность модели

1. **Типовые операции** - чат-бот, рассылки
2. **Автоматические follow-up** - напоминания
3. **Анализ данных** - воронка продаж
