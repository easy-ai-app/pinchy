## Детальный анализ приложений

### ChatGPT (Официальное приложение)

**Комментарий из исследования**: 
"После недели тестирования понял главное: Claude не заменяет ChatGPT, а дополняет его. Как швейцарский нож и мачете — лучше уметь пользоваться обоими."

**Функционал**:
- Deep Research для аналитики
- Мульти-модальность (текст, изображения, голос)
- Интеграция с DALL-E для генерации изображений
- Code Interpreter для выполнения кода
- File uploads для анализа документов

**Плюсы**:
- Самая зрелая экосистема
- Максимальный функционал
- Регулярные обновления

**Минусы**:
- Высокая стоимость подписки Plus
- Требует стабильного интернета
- Некоторые функции только в веб-версии

## Гигачат (Мобильное приложение)

### Сбер

**Аудитория**: ~3 млн активных пользователей в месяц

**Функции**:
- Чат-бот в Telegram
- Генерация изображений (Kandinsky)
- Создание музыки
- Распознавание текста и объектов на фото
- Работа с PDF до 200 страниц
- Расшифровка голосовых в групповых чатах

**Плюсы**:
- Бесплатный доступ
- Отличное понимание русского языка
- Интеграция с Telegram
- Генерация музыки до 3 минут

**Минусы**:
- Требуется Сбер ID
- Может терять нить диалога

## Платные vs Бесплатные функции

### Типичные ограничения бесплатных версий

| Функция | Бесплатно | Платно |
|---------|-----------|--------|
| Текстовые запросы | 10-20/день | Безлимит |
| Генерация изображений | 3-5/день | Безлимит |
| Анализ файлов | Нет | Да |
| Голосовой ввод | Ограничен | Полный |
| История диалогов | 10-15 сообщений | Безлимит |
| Модели | GPT-3.5 | GPT-4, Claude |

## Тренды мобильных AI приложений

### 1. Агрегация моделей

Приложения объединяют несколько AI-моделей в одном интерфейсе:
- Сравнение ответов
- Выбор оптимальной модели для задачи
- Экономия на подписках

### 2. Мини-приложения (Mini App)

Telegram Mini Apps становятся популярным форматом:
- Не требуют установки
- Доступ к широкому функционалу
- Интеграция с платежами

### 3. Голосовое управление

Увеличение доли голосового ввода:
- Распознавание речи
- Озвучка ответов
- Клонирование голоса

### 4. Мульти-модальность

Приложения поддерживают:
- Текст
- Изображения
- Видео
- Аудио
- Документы
