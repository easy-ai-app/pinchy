## Session Overview

**Topic:** Создание аналога Manus для СНГ
**Goals:** Разработка продукта для нетехнических пользователей: МСБ, блогеры, фрилансеры, менеджеры, продавцы

### Context Guidance

**Ключевые инсайты из исследований:**

**Manus AI (эталон):**

- Полностью автономный AI-агент, выполняющий многошаговые задачи
- Мульти-агентная архитектура (Planner, Executor, Verifier)
- Web-автоматизация, код-генерация, исследования, презентации
- Ценообразование: $19-199/мес, ~$2 за задачу
- Приобретён Meta за $2+ млрд

**Рынок СНГ:**

- 86% руководителей верят, что ИИ-агенты повысят эффективность к 2027
- 60-70% блогеров используют ИИ (самый высокий охват)
- 20-25% МСБ используют ИИ (самый низкий охват)
- Основные барьеры: стоимость, доступ специалистов, качество данных

**Конкуренты:**

- Telegram-боты (UNISET, MAZAI, СИНТАКС, GPT TUNNEL): 200-700₽/мес
- CRM с ИИ (Битрикс24, amoCRM, МойСклад): 999-4990₽/мес
- Российские LLM: GigaChat (бесплатно), YandexGPT (бесплатно)

**Целевые сегменты:**

1. Селлеры маркетплейсов (35-40% используют ИИ)
2. Блогеры/инфлюенсеры (60-70% используют ИИ)
3. Фрилансеры (50-60% используют ИИ)
4. МСБ (20-25% используют ИИ)

**Боли пользователей:**

- Сложность интеграции
- Недостаток специалистов
- Высокая стоимость Enterprise-решений
- Ограниченный контекст у Telegram-ботов (10-15 сообщений)
- Нет VPN-free доступа к топовым решениям
