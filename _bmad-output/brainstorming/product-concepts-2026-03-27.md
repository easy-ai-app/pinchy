## Concept 1: Extension Secretary Pro

**Tagline:** "Секретарь в браузере за 500₽/мес"

### Blend
| Компонент | Источник |
|-----------|----------|
| Browser Extension | Core Product |
| Транскрибация + Summary | Secretary |
| Битрикс24/amoCRM интеграция | CRM-First Insight |
| 30-секундный onboarding | Zero-Friction UI |
| Free tier (5 calls) | Value-First Monetization |
| Русский язык + Telegram | CIS-Market |

### Product Description
Chrome/Firefox extension, который автоматически распознаёт речь на созвонах (Zoom, Meet, Telegram), создаёт summary с action items и синхронизирует в CRM. Устанавливается за 15 секунд, первый созвон — бесплатно.

### Target Segment
| Первичный | Продавцы (SMB sales) |
|-----------|---------------------|
| Вторичный | Фрилансеры |
| Третичный | Блогеры |

### Key Features
- Авто-детект звонка (Zoom, Meet, Telegram, VK)
- Real-time транскрибация (GigaChat/YandexGPT)
- Summary с таймкодами
- Action items с исполнителями
- One-click export в Битрикс24/amoCRM/Telegram
- Поиск по всем созвонам

### Business Model
| Tier | Price | Features |
|------|-------|----------|
| Free | 0₽ | 5 calls/month |
| Lite | 500₽/мес | Unlimited calls, summary |
| Pro | 1500₽/мес | + CRM sync, analytics |
| Team | 500₽/чел | Командные функции |

### Competitive Advantage
| Manus | Extension Secretary Pro |
|-------|------------------------|
| $19-199/мес | 500-1500₽/мес |
| Платформа | Extension (всегда под рукой) |
| Английский | Русский first |
| Western CRM | Битрикс24/amoCRM |
| Сложный start | 15 секунд до value |

### MVP (1 месяц)
- Extension core
- Транскрибация
- Summary + Actions
- Telegram export
- Free tier

### Revenue Projection (Year 1)
| Месяц | Users | Revenue |
|-------|-------|---------|
| 1-3 | 100-500 | 50K-250K₽ |
| 4-6 | 500-2000 | 250K-1M₽ |
| 7-12 | 2000-10000 | 1M-5M₽ |

## Concept 2: Modular Agent Builder

**Tagline:** "Собери своего ИИ-агента как в IKEA"

### Blend
| Компонент | Источник |
|-----------|----------|
| Модульная архитектура | IKEA Cross-Pollination |

| Покупай только нужное | Modular Pricing |
| Marketplace готовых агентов | UGC Marketplace |

### Product Description
No-code платформа для создания кастомных ИИ-агентов. Пользователь выбирает модули (как в IKEA), собирает визуально (как в Figma), настраивает под свои данные. Готовые агенты можно продавать на marketplace.

|-----------|-------------------------------|
| Вторичный | Фрилансеры (перепродажа агентов) |
| Третичный | Enterprise (белый label) |

### Key Features
- Визуальный конструктор (drag & drop)
- Библиотека модулей: Триггеры, Действия, Условия, Результаты
- Templates для частых сценариев
- "Обучи агента" на своих данных
- Marketplace: Покупай/продавай агентов
- Fork чужих агентов

### Modules Pricing

| Продавец | 500₽/мес | Scripts + CRM |
| Аналитик | 700₽/мес | Insights |
| Память | 400₽/мес | Search + KB |

### Competitive Advantage
| Competitors | Modular Agent Builder |
|-------------|----------------------|

| $19-199/мес за всё | Плати только за нужное |
| Нельзя кастомизировать | No-code конструктор |
| Нельзя монетизировать | Marketplace для UGC |

### MVP (2 месяца)

- 3 готовых template
- Базовый marketplace

## Concept 3: Business Fitness Tracker

**Tagline:** "Apple Watch для твоего бизнеса"

### Blend
| Компонент | Источник |
|-----------|----------|
| Streaks & Goals | Fitness/Gaming |
| Biomarkers | Biohacking |
| Leaderboards | Fantasy League |
| Time-Back | Fintech |
| Team Competition | Sports |

### Product Description
ИИ-агент трекает бизнес-метрики как фитнес-трекер. Streaks за выполненные задачи, цели на неделю, соревнования с командой, визуализация прогресса. Показывает не "сэкономлено X часов", а "сэкономлено X рублей".

### Target Segment
| Первичный | Команды продаж (5-50 чел) |
|-----------|--------------------------|
| Вторичный | Фрилансеры (solo) |
| Третичный | Блогеры (metrics) |

### Key Features
- Streaks: "Созвонов без пропуска follow-up"
- Goals: "Закрыть 5 сделок" → агент трекает
- Time-Back: "Сэкономлено 47ч = 9,400₽"
- Leaderboard: MVP недели в команде
- Biomarkers: Talk ratio, questions, deal probability
- Уровни: "Агент достиг уровня 5"

### Gamification
| Element | Function |
|---------|----------|
| Daily streak | Ежедневное использование |
| Weekly goals | Цели на неделю |
| Achievements | Бейджи за результаты |
| Leaderboard | Соревнование в команде |
| Gacha boost | Случайные бонусы |

### Pricing
| Tier | Price | Features |
|------|-------|----------|
| Free | 0₽ | Solo, базовые streaks |
| Team | 500₽/чел | Leaderboards, metrics |
| Enterprise | Договор | Custom, API |

### Competitive Advantage
|传统的 CRM | Business Fitness Tracker |
|----------|--------------------------|
| Скучные метрики | Gamified progress |
| Нет мотивации | Streaks & rewards |
| Без контекста | Time-Back в рублях |
| Solo | Team competition |

## Concept 6: Doctor-Agent for Business

**Tagline:** "Врач для твоего бизнеса — диагностика, лечение, выздоровление"

### Blend
| Компонент | Источник |
|-----------|----------|
| Анамнез | Healthcare |
| Диагноз | Medical |
| Рецепт | Prescription |
| Follow-up | Check-up |
| Biomarkers | Biohacking |

### Product Description
ИИ-агент как бизнес-врач. Проводит диагностику (анамнез), выявляет проблемы (диагноз), прописывает решения (рецепт), следит за улучшением (follow-up). Показывает "биомаркеры здоровья бизнеса".

### Process
| Stage | Doctor-Agent |
|-------|--------------|
| **Анамнез** | История всех созвонов, задач, результатов |
| **Диагностика** | AI анализ: "Потеря 23% лидов на этапе X" |
| **Диагноз** | "Проблема: нет follow-up в течение 48ч" |
| **Рецепт** | "Решение: авто-напоминания + скрипты" |
| **Лечение** | Автоматическое применения решения |
| **Follow-up** | Через неделю: "Улучшение на 15%" |
| **Профилактика** | Регулярные check-ups |

### Biomarkers
| Biomarker | Healthy Range |
|-----------|---------------|
| Response time | < 4 hours |
| Follow-up rate | > 80% |
| Deal velocity | > baseline |
| Client satisfaction | > 4.5/5 |
| Team talk ratio | 40/60 |

### Pricing
| Tier | Price | Features |
|------|-------|----------|
| Basic | 500₽/мес | Диагностика + Рецепты |
| Pro | 1500₽/мес | + Авто-лечение |
| Enterprise | 5000₽/мес | + Командный мониторинг |

### Competitive Advantage
| Аналитика | Doctor-Agent |
|-----------|--------------|
| "Вот данные" | "Вот диагноз и лечение" |
| Разрозненные отчёты | Медицинский подход |
| Нет follow-up | Регулярные check-ups |
| Реактивный | Проактивный |
