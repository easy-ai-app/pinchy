# Product Brief: Pinchy

## Executive Summary

Фрилансер в Москве тратит 2-3 часа в день на рутину: поиск заказов, follow-up с клиентами, запросы в МойСклад. SMM-специалист тратит часы на контент-планирование для 11 соцсетей. Офисный сотрудник тонет в 120 письмах в день.

Они слышали про Manus AI — автономные агенты, которые работают 24/7. Но $40/мес + VPN + английский интерфейс + нет интеграций с российскими сервисами. Не вариант.

Pinchy — это Manus для СНГ. Российский SaaS с автономными AI-агентами для фрилансеров, блогеров, малого бизнеса и офисных сотрудников. Веб-приложение за 499–1,499 ₽/мес. Без VPN. На русском. С интеграциями в МойСклад, Weeek, amoCRM, ЯндексТаблицы.

**Одно предложение:** Pinchy — автономные AI-агенты 24/7 для массового рынка СНГ.

## Проблема

**Рутина съедает время.**

Фрилансер в России работает 8 часов, из них 5-6 — billable. Остальное: поиск заказов на биржах (50-100 откликов на проект), follow-up с клиентами (забыл перезвонить = потерял клиента).

SMM-специалист тратит часы на контент-планирование. Блогер публикует в 11 соцсетей вручную. Аналитика разрознена — LiveDune, Popsters, JagaJam — нет единого окна.

Офисный сотрудник получает 120 писем в день, проводит 23 часа в неделю на встречах, собирает отчёты из разных систем вручную.

| Сегмент | Размер | Боль |
|---------|--------|------|
| Фрилансеры | 2+ млн в РФ | 60-70% времени — не работа, а рутина |
| Блогеры/SMM | Рынок 65 млрд ₽ (+35%) | Контент-планирование = часы каждый день |
| Малый бизнес | 1.5+ млн в РФ | Не может позволить себе ассистента |
| Офисные сотрудники | Corporate | 120 писем/день, 23 ч встреч/неделя |

**Мировые решения недоступны.**

Manus AI ($39-199/мес), ChatGPT Operator, Anthropic Claude — все требуют VPN, английского интерфейса, западных платежей. Интеграции с Salesforce, Notion, Google Sheets — бесполезны для российского рынка.

**Локальные решения — не агенты.**

GigaChat, YandexGPT — чат-боты. Отвечают на вопросы, но не выполняют задачи автономно. "Follow-up за клиентом через 3 дня" — нужна агентная логика, которой у них нет.

**Специалисты пробовали n8n, Dify.**

Low-code платформы для автоматизации. Но нужен технарь для настройки. Фрилансер без SQL-запросов workflow не построит. Это инструмент для разработчика, не для предпринимателя.

## Решение

Pinchy — SaaS-платформа автономных AI-агентов для СНГ.

**Агент 24/7.** Не чат-бот. Агент получает задачу ("найди клиентов на Kwork, которые искали дизайнеров логотипов на этой неделе"), планирует шаги, выполняет автономно. Пользователь получает результат, не промежуточные вопросы.

**Интеграции с СНГ-сервисами.**

| Категория | Интеграции MVP | Phase 2 |
|-----------|----------------|---------|
| CRM | МойСклад, amoCRM, Битрикс24 | — |
| Задачи | WEEEK, ЯндексТаблицы | — |
| Коммуникации | Telegram, Email | — |
| Аналитика | LiveDune, Popsters (сводные отчёты) | Brand Analytics, IQBuzz, YouScan |
| Автопостинг | — | SMMplanner, SmmBox |
| Поиск | Web scraping, парсинг лидов | — |

**Белые пятра закрывает Pinchy:**
- Единое окно для всех каналов (вместо разрозненных LiveDune + Popsters + SMMplanner)
- Автономные агенты (вместо чата GigaChat или workflow n8n)
- Без технаря (вместо Albato/Make за 1999-5000₽/мес)

**Веб-приложение.** PWA, работает в браузере. Регистрация за 30 секунд через Telegram или email. Первый агент создаётся из шаблона за 2 минуты.

**Шаблоны агентов.** Не "создай агента с нуля". Пользователь выбирает: "Поиск лидов", "Follow-up менеджер", "Мониторинг конкурентов", "Контент-планирование", "Email-ассистент". Шаблон преднастроен, пользователь адаптирует под себя.

**Кредитная система.** 1 кредит = 1 действие агента (tool call). Прозрачность расходов. Free tier: 3-5 задач/день для aha-moment. Платные тарифы: 499/949/1,499 ₽/мес.

**Yandex Cloud.** Серверы в РФ (152-FZ compliance). Данные не покидают страну.

| **Интеграции СНГ** | МойСклад, Weeek, amoCRM, ЯТ | Западные сервисы | Нет интеграций | Есть, но нужен технарь |

2. Русский язык и СНГ-интеграции
3. Цену для массового рынка (не enterprise)
4. Для не-технических юзеров (шаблоны, не конструктор)

## Белые пятна на рынке СНГ

**Где существующие решения не закрывают потребности:**

| Сегмент | Белое пятно | Как Pinchy решает |

| Фрилансеры | Follow-up без ручной настройки | Агент24/7 напоминает, пишет статус |

| SMB | Единое окно для всех каналов (CRM + мессенджеры + email) | Telegram/Email интеграции в одном агенте |

**Конкуренты не закрывают:**
- GigaChat/YandexGPT — чат, не агенты
- n8n/Dify — нужен технарь

## Кому нужно

**Первичный сегмент: Фрилансеры (P0)**

2+ млн в России. 60-70% времени — рутина, неbillable работа.

| Профиль | Боль | Pinchy решает |
|---------|------|---------------|
| Дизайнер, иллюстратор | 2-3 ч/день на поиск заказов | Автоматический мониторинг бирж |
| Маркетолог-фрилансер | Follow-up проваливается | Агент напоминает, пишет статус |
| Копирайтер | Рутина съедает billable | Шаблоны ответов, база знаний |
| Разработчик-фрилансер | Документы вручную | Авто-КП, счета |

**Вторичный сегмент: Блогеры и SMM (P0)**

Рынок 65 млрд₽, +35% рост в 2024. Контент-планирование = часы каждый день.

| Профиль | Боль | Pinchy решает |
|---------|------|---------------|
| SMM-менеджер | Контент-планирование = часы/день | Авто-планирование, календарь |
| Блогер | 11 соцсетей для публикации | Кросс-постинг, автопубликация |
| Контент-мейкер | Аналитика разрознена по системам | Сводные отчёты, единое окно |
| Бренд-менеджер | Мониторинг конкурентов вручную | Авто-мониторинг, уведомления |

1.5+ млн в России. Не могут позволить себе ассистента.

**Пятый сегмент: Инвесторы (P2, Phase 2)**

| Профиль | Боль | Pinchy решает |

## Scope

**In Scope — MVP**

| Категория | Функционал |
|-----------|------------|
| Аутентификация | Email/password, Telegram OAuth |
| Провайдеры LLM | GigaChat, YandexGPT, DeepSeek |
| Агенты | Создание из шаблонов (5-10 MVP), кастомизация |
| Интеграции | МойСклад, Weeek (готовые из Laretz), Telegram, Email |
| Биллинг | Кредитная система, ЮKassa/СБП |
| Инфраструктура | Yandex Cloud, Docker Compose |

**In Scope — Post-MVP (Phase 2)**

- Дополнительные интеграции: amoCRM, Битрикс24, ЯндексТаблицы
- Маркетплейс шаблонов (user-generated)
- Расширенная аналитика для юзера
- Шаблоны для офисных сотрудников

**In Scope — Enterprise (Phase 3)**

- Self-hosted опция для корпораций
- Расширенные права доступа
- SLA и техподдержка
- Интеграции с корпоративными системами

**Explicitly Out of Scope**

- Managed cloud hosting (не в России — только SaaS на Yandex Cloud)
- Mobile native apps (PWA-first)
- Enterprise-first подход (сначала массовый рынок)
- Западные интеграции (Salesforce, Notion, Google Sheets — не для СНГ)

## Риски и митигация

| Риск | Уровень | Митигация |
|------|---------|-----------|
| LLM API cost volatility (YandexGPT/GigaChat pricing) | Критический | Моделирование costs, multi-provider стратегия, credit pacing |
| Конкурентный ответ (Yandex/Sber) | Высокий | First-mover advantage, интеграции, platform lock-in |
| DeepSeek доступность в РФ | Высокий | Multi-provider (GigaChat, YandexGPT, DeepSeek), fallback стратегии |
| Юнит-экономика при heavy users | Высокий | Credit limits per tier, overage pricing, fair use policy |
| Non-technical user adoption | Средний | Шаблоны, onboarding, Watson-style assistant |

## Vision

**Год 1:** Самый доступный AI-агент для фрилансеров, блогеров и SMB в России. 1,000+ платных юзеров. Word-of-mouth Growth.

**Год 2:** Стандарт для автоматизации рутины в СНГ. Маркетплейс шаблонов. Интеграции с основными СНГ-сервисами. Расширение в Казахстан, Беларусь.

**Год 3:** Платформа для бизнеса любого размера. Enterprise-сегмент с self-hosted опцией. API для разработчиков. Экосистема интеграций.

**Куда это идёт:** Каждый фрилансер, блогер и SMB в СНГ имеет AI-агента, который работает 24/7. Рутина автоматизирована, люди фокусируются на творчестве и стратегии. Pinchy — AI-ассистент для рынка СНГ.
