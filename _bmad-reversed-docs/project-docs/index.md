## Project Overview

Pinchy is an enterprise AI agent platform built on top of OpenClaw, the open-source AI agent runtime. It adds the governance layer enterprises require: authentication, role-based access control, agent permissions (allow-list model), user management with invite system, groups, HMAC-SHA256 signed audit trail, usage tracking with cost estimation, and Docker Compose deployment. The platform bridges browser clients to OpenClaw via a WebSocket server, wrapping every interaction in permission checks and audit logging.

## Getting Started

### Prerequisites

- Docker and Docker Compose
- Node.js 22 (for tests/linting outside Docker)
- pnpm 10.29.3

### Setup

```bash
git clone https://github.com/heypinchy/pinchy.git
cd pinchy
pnpm install
```

### Run Locally

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```

### Run Tests

```bash
pnpm test
```

### Key Patterns to Follow:

1. **Every state-changing API route needs `appendAuditLog()`** -- see `architecture.md` security section
2. **Agent access checks** -- use `assertAgentAccess()` from `lib/agent-access.ts`
3. **Enterprise gating** -- use `isEnterprise()` from `lib/enterprise.ts`
4. **Settings storage** -- use key-value `settings` table with optional encryption
5. **New DB tables** -- add to `src/db/schema.ts`, run `pnpm db:generate`
6. **New API routes** -- follow pattern in `src/app/api/`, include auth middleware + audit logging
